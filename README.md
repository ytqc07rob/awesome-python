# Awesome Python

A curated list of awesome Python frameworks, libraries, software and resources.

## Data Analysis

*Libraries for data manipulation and analysis.*

* [Pandas](https://pandas.pydata.org/) - A library providing high-performance, easy-to-use data structures and data analysis tools.
* [Polars](https://pypolars.org/) - Fast multi-threaded DataFrame library implemented in Rust.
* [DuckDB](https://duckdb.org/) - An in-process SQL OLAP database management system.
* [NumPy](https://numpy.org/) - A fundamental package for scientific computing with Python.
* [SciPy](https://scipy.org/) - A Python-based ecosystem of open-source software for mathematics, science, and engineering.
* [Dask](https://dask.org/) - Flexible library for parallel computing in Python.
* [Vaex](https://vaex.io/) - A high-performance Python library for lazy Out-of-Core DataFrames.

## Data Validation

*Libraries for validating data structures.*

* [Pydantic](https://docs.pydantic.dev/) - Data validation using Python type hints.
* [Great Expectations](https://greatexpectations.io/) - A tool that helps data teams eliminate pipeline debt through data testing, documentation, and profiling.
* [Pandera](https://pandera.readthedocs.io/) - A light-weight, flexible data validation library for dataframes.

## Data Pipelines

*Libraries for building data pipelines.*

* [Apache Airflow](https://airflow.apache.org/) - Platform to programmatically author, schedule, and monitor workflows.
* [Prefect](https://www.prefect.io/) - A modern workflow orchestration engine.
* [Dagster](https://dagster.io/) - An orchestration platform for the data lifecycle.
* [Luigi](https://github.com/spotify/luigi) - A Python module that helps you build complex pipelines of batch jobs.
